# Food Store - Frontend

Aplicación React + TypeScript + Vite con Tailwind CSS.

## Requisitos

- Node.js 20.19 o superior
- pnpm 9 o superior
- Backend iniciado en http://localhost:8000

## Configuración

Desde la carpeta `frontend`, copiá `.env.example` como `.env`:

```powershell
Copy-Item .env.example .env
